## What I work on

**Salesforce delivery**

- **Quote-to-cash:** CPQ, Billing and Agentforce for a payments provider in financial services
- **Agentforce agents for the public sector:** customer-facing agents, from conversation design to testing and release
- **Org health:** deep performance audits and org assessments of large orgs, where every finding is reproduced against the live org before it is reported
- **Non-profit and philanthropy:** a migration from a custom budget model to standard Grantmaking, and Nonprofit Cloud fundraising

**AI for Salesforce delivery**

- **Company-wide AI skills library:** I built and maintain the library that puts asUgo's Salesforce best practices into every consultant's AI assistant. It has 100 skills, 13 specialist agents, 13 hooks and 17 commands for Claude Code and Cursor, covering Apex, Flow, LWC, SOQL, Data Cloud, OmniStudio and Agentforce, plus DevOps, security, GDPR and branded client deliverables. Every consultant gets the same standards on every project, from the first line of code to the final client document. Consultants find skills through an internal AI portal, every skill passes a validator in CI, and the library exports to six other AI coding tools.
- **Multi-agent review and audit:** orchestrators that plan, test and review Salesforce work with several AI reviewers. Each finding is re-derived independently and challenged before it reaches a client.

**Products**

- **Dev Cockpit:** a managed package for error logging, monitoring and GDPR privacy requests, installed in client production and sandbox orgs
- **asuTest:** test automation with a Salesforce control plane and a TypeScript orchestrator
